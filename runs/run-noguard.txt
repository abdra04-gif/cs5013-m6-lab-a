```java
// File: sample-repo/com/example/util/FinePolicy.java
@Override
public BigDecimal computeFine(Loan loan, LocalDate today) {
    if (!loan.isOverdue(today)) {
        return BigDecimal.ZERO;
    }
    long daysLate = ChronoUnit.DAYS.between(loan.getBorrowedOn(), today)
            - Loan.DEFAULT_TERM_DAYS;
    BigDecimal fine = PER_DAY.multiply(BigDecimal.valueOf(daysLate));
    return fine.compareTo(CAP) > 0 ? CAP : fine;
}
```

This method takes into account the loan's overdue status and calculates the fine based on the number of days late.

```java
public List<Book> searchByTitle(String needle) {
    String lower = needle.toLowerCase();
    List<Book> out = new ArrayList<>();
    for (Book b : byIsbn.values()) {
        if (b.getTitle().toLowerCase().contains(lower)) {
            out.add(b);
        }
    }
    return out;
}
```
